How to Use and Format Specifications

How to convert JSON to CSV locally

  1. Upload a JSON file containing a top-level array of objects.
  2. Verify CSV is selected as the target format.
  3. Click Convert and download your RFC 4180-compliant CSV file.

Technical specifications & limitations

Important format notes: Input JSON must be formatted as a top-level array of objects (e.g., [{"id": 1, "name": "Item"}]). Unstructured or primitive JSON arrays cannot be tabularized.

Client-side privacy guarantee

FormatFoundry executes this conversion entirely within your browser runtime using standard Web APIs. No document, image bytes, metadata, or telemetry are ever uploaded to remote servers or third-party analytical endpoints.

Frequently asked questions

What shape must my JSON file have?

The JSON file must have a top-level array containing objects. Each object represents a row in the resulting CSV spreadsheet.

How are commas and quotes inside JSON values handled?

FormatFoundry follows RFC 4180 standards: fields containing commas, line breaks, or double quotes are wrapped in quotation marks, and inner quotes are escaped as double-quotes ("").
