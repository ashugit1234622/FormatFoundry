How to Use and Format Specifications

How to convert JSON to CSV locally

  1. Upload a JSON file containing a top-level array of objects, single object, or record array wrapper.
  2. Verify CSV is selected as the target format in the staged item controls.
  3. Click Convert and download your RFC 4180-compliant CSV file.

Technical specifications & limitations

Important format notes: Heterogeneous mixed arrays containing both primitive values and objects are rejected with clear diagnostics. Large datasets exceeding 50 MB should be partitioned before conversion.

Client-side privacy guarantee

FormatFoundry executes this conversion entirely within your browser runtime using standard Web APIs. No document, image bytes, metadata, or telemetry are ever uploaded to remote servers or third-party analytical endpoints.

Frequently asked questions

What JSON structures can this tool convert to CSV?

FormatFoundry natively handles four primary JSON structures: (1) an array of flat objects, (2) a single object converted to a 1-row table, (3) wrapper objects containing a record array (such as {"airports": [...]}), and (4) an array of primitive values converted into a single-column table with a "value" header.

What happens if a JSON object has an empty key or missing properties?

Empty property names are automatically assigned deterministic fallback headers like "column_unnamed_1" with a clear warning so no cell data is lost. Records with missing properties produce empty cells in the appropriate column without shifting subsequent values.

How are commas, line breaks, and quotation marks escaped in the CSV?

FormatFoundry follows RFC 4180 specifications: any cell containing commas, CRLF/LF line breaks, or double quotes is enclosed in quotation marks, and inner quotes are escaped by doubling them (""). Output is validated with a delimiter parser before completion.
