How to Use and Format Specifications

How to convert HTML to Markdown locally

  1. Drop your .html or .htm file into the staging workspace.
  2. Select Markdown (.md) as the conversion target.
  3. Click Convert to generate clean GFM Markdown instantly.

Format specifications & engine handling

Supported Input HTML documents and snippets (.html, .htm)
Available Targets Markdown documentation (.md)
Processing Engine Client-Side JavaScript & HTML5
Privacy Model 100% Local (0 Network Uploads)
  • Converts headings, paragraphs, lists, links, images, and blockquotes
  • Full GitHub Flavored Markdown table support with alignment
  • Powered by Turndown with GFM extensions client-side
  • 100% private in-browser conversion with zero telemetry

Technical specifications & limitations

Important format notes: Complex JavaScript, inline scripts, and CSS style blocks are automatically stripped out during markup conversion.

Client-side privacy guarantee

FormatFoundry executes this conversion entirely within your browser runtime using standard Web APIs. No document, image bytes, metadata, or telemetry are ever uploaded to remote servers or third-party analytical endpoints.

Yes. Full HTML files or snippet fragments convert into clean Markdown documentation.
