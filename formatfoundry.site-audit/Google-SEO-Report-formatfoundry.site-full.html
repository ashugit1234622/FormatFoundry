1. Executive Summary

This report presents a comprehensive SEO audit of formatfoundry.site for a Web Utility / SaaS Tool site, generated on October 30, 2026. Findings combine technical, content, schema, performance, visual, and search-readiness evidence as available.

79/100
SEO Health Score
Critical Issues Found:
  1. Active CSP header blocks Google Fonts and Cloudflare Web Analytics beacon, causing browser console errors on every page load.
  2. Missing trailing-slash tool paths return HTTP 307 Temporary Redirect instead of HTTP 301 Permanent Redirect, diluting link equity consolidation.
  3. Google-deprecated HowTo schema and retired FAQPage SERP markup present across all 38 tool routes.
  4. CSS @import for Google Fonts creates a render-blocking waterfall that delays First Contentful Paint.
  5. Missing /llms.txt discovery file and structured entity graph linking tools to a verified Organization publisher.
Quick Wins:
  1. Self-host Plus Jakarta Sans and JetBrains Mono locally in WOFF2 format to resolve CSP errors and eliminate render-blocking @import.
  2. Populate public/_redirects with all 38 tool paths mapping non-slash URLs to trailing-slash URLs with 301 status.
  3. Deploy public/llms.txt to provide AI search engines (Perplexity, ChatGPT, Claude) with structured tool definitions.
  4. Add <script type="speculationrules"> for instant hover prerendering of high-traffic tools.
  5. Connect disconnected schema objects into a unified @graph with Organization publisher node.

2. Audit Categories

2.1 Technical SEO

Score: 82/100

What Works

  • 100% pre-rendered semantic HTML with zero client-side rendering blank shell risks
  • Valid sitemap.xml with 40 URLs declared in robots.txt
  • Self-referencing canonical tags on all published routes
  • Cloudflare HTTP/3 and edge compression (zstd/gzip) enabled
  • Strict HTTP 404 response on unknown probe URLs

Findings

CSP Header Blocks Fonts and Analytics Critical

CSP header style-src and script-src directives omit fonts.googleapis.com, fonts.gstatic.com, and static.cloudflareinsights.com, throwing console errors and blocking external fonts.

Recommendation: Self-host fonts locally with WOFF2 and @font-face or update CSP header directives to whitelist required origins.

Non-Trailing-Slash URLs Return 307 Temporary Redirect High

Requesting /png-to-jpg triggers a 307 Temporary Redirect to /png-to-jpg/ instead of a 301 Permanent Redirect.

Recommendation: Add 301 redirect rules for all 38 tools into public/_redirects.

2.2 Content Quality & E-E-A-T

Score: 76/100

What Works

  • Zero filler or generic AI marketing cliches across all tools
  • Accurate technical documentation of client-side browser conversion mechanics
  • Clear transparent privacy assurances

Findings

Templated Repetitive Language Across 38 Tools Medium

content_quality.py flagged repetition score of 37 due to shared boilerplate privacy and upload instructions.

Recommendation: Introduce unique format comparison tables, benchmark matrices, and practical workflow examples per tool.

Missing Author Byline & Dedicated About/Privacy Pages High

Header links for About and Privacy point to short homepage hash fragments; no author entity or cryptographic audit is documented.

Recommendation: Create dedicated /about/ and /privacy/ pages with engineering background, GitHub repo link, and DevTools privacy verification.

2.3 On-Page SEO

Score: 88/100

What Works

  • Unique descriptive <title> tags on all 40 published routes
  • Targeted meta descriptions within 120-160 character boundary
  • Strict single <h1> and semantic heading hierarchy
  • Visible HTML breadcrumbs and matching JSON-LD BreadcrumbList
  • Complete OpenGraph and Twitter card metadata with 1200x630px social image

Findings

Internal Link Context Limited to End-of-Page Grid Low

Internal cross-links between related tools exist only in a footer card grid without inline contextual body links.

Recommendation: Add contextual cross-references in format conversion explanations (e.g. mention WebP in PNG conversion copy).

2.4 Schema / Structured Data

Score: 72/100

What Works

  • Valid JSON-LD without syntax errors on every page
  • WebApplication schema on all conversion tools
  • CollectionPage and ItemList schema on /tools/ directory
  • BreadcrumbList schema on all tool pages

Findings

Deprecated HowTo Schema Present on All Tools Medium

Google officially deprecated HowTo rich results in September 2023. Continuing to emit HowTo schema adds payload without SERP benefit.

Recommendation: Remove HowTo schema block from build-seo-pages.js to save ~1.2 KB JSON-LD per page.

Disconnected Schema Objects Without Entity Graph Medium

JSON-LD emits top-level array of anonymous objects rather than a connected @graph with Organization publisher and @id links.

Recommendation: Refactor JSON-LD into a unified @graph with Organization, WebSite, and WebApplication entities.

2.5 Performance (Core Web Vitals)

Score: 78/100

What Works

  • Static HTML footprint under 14 KB
  • Vite-bundled JavaScript and CSS with cache-busting hashes
  • Sub-50ms TTFB across Cloudflare global edge network
  • Zero blocking third-party tracking scripts

Findings

CSS @import Google Fonts Cascade High

src/styles/main.css line 1 imports Google Fonts via CSS @import, chaining stylesheet requests and delaying FCP/LCP.

Recommendation: Self-host font files locally or move stylesheet link to HTML head with preconnect.

Zero Modern Preload and Speculation Rules Medium

Preload audit score was 50/100; no Speculation Rules or resource hints exist for top navigation paths.

Recommendation: Implement Speculation Rules API on homepage and tools directory for instant prerendering.

2.6 AI Search Readiness & GEO

Score: 68/100

What Works

  • Content completely readable without JavaScript execution (359 words SSR)
  • Zero robot disallows for AI search crawlers in robots.txt
  • Clear differentiation as zero-upload client-side privacy tool

Findings

Missing /llms.txt and /llms-full.txt High

agentic_check.py returned HTTP 404 for /llms.txt, missing out on direct indexing by AI agents and LLM citation engines.

Recommendation: Deploy public/llms.txt detailing all 38 tools and client-side processing guarantees.

Missing Outbound Authoritative RFC Links Low

Tool pages lack outbound citations to official specifications (RFC 4180, W3C SVG2) that boost generative authority.

Recommendation: Add links to IETF and W3C standards on data and SVG tool pages as outlined in PROMOTION.md.
