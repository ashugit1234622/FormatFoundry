How to Use and Format Specifications

How to convert Markdown to HTML locally

  1. Upload a Markdown (.md, .markdown) document.
  2. Confirm HTML is set as the target format.
  3. Click Convert and download your compiled, sanitized HTML file.

Technical specifications & limitations

Important format notes: Raw HTML tags inside Markdown are sanitized using strict DOMPurify rules; dangerous tags like <script>, <iframe>, and inline event handlers are stripped for security.

Client-side privacy guarantee

FormatFoundry executes this conversion entirely within your browser runtime using standard Web APIs. No document, image bytes, metadata, or telemetry are ever uploaded to remote servers or third-party analytical endpoints.

Frequently asked questions

Is the output HTML sanitized against XSS attacks?

Yes. All compiled HTML is sanitized using DOMPurify to eliminate malicious scripts, iframes, and hazardous attributes before generating the output file.

Does this converter support tables and fenced code blocks?

Yes. The converter supports GitHub-Flavored Markdown specifications including markdown tables, code syntax highlighting blocks, and task lists.
