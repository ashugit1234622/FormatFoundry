How to Use and Format Specifications

How to convert Markdown to PDF locally

  1. Drop your .md Markdown file into the workspace.
  2. Choose PDF Document as the output format.
  3. Click Convert to generate a formatted PDF document instantly.

Format specifications & engine handling

Supported Input Markdown files (.md, .markdown)
Available Targets PDF documents (.pdf)
Processing Engine Client-Side JavaScript & HTML5
Privacy Model 100% Local (0 Network Uploads)
  • Renders H1, H2, H3 headings with hierarchical sizing
  • Supports bullet lists, blockquotes, and code blocks
  • Automatic page wrapping with bottom page numbers
  • Zero server upload ensures documentation privacy

Technical specifications & limitations

Important format notes: Complex raw HTML embedded within Markdown is stripped for clean PDF pagination.

Client-side privacy guarantee

FormatFoundry executes this conversion entirely within your browser runtime using standard Web APIs. No document, image bytes, metadata, or telemetry are ever uploaded to remote servers or third-party analytical endpoints.

Frequently asked questions

Does this support standard Markdown syntax?

Yes. Headings, bulleted lists, quotes, inline code, and paragraphs are formatted into styled PDF elements.

Is my Markdown document kept private?

Yes. Processing occurs entirely in your browser sandbox without network requests.
