How to Use and Format Specifications

How to convert Image Inspector locally

  1. Select or drag PNG, JPEG, WebP, or SVG files into the workspace.
  2. View the detected binary signature, browser MIME type, pixel dimensions, and aspect ratio.
  3. Check browser decodability to verify whether the image file is valid or corrupted.

Technical specifications & limitations

Important format notes: Inspection examines binary magic bytes, image dimensions, and decodability. It does not extract EXIF, GPS, or color profile tags unless verified by browser rendering.

Client-side privacy guarantee

FormatFoundry executes this conversion entirely within your browser runtime using standard Web APIs. No document, image bytes, metadata, or telemetry are ever uploaded to remote servers or third-party analytical endpoints.

Frequently asked questions

How does the inspector detect corrupted files?

It compares binary header magic bytes against standard specifications and attempts browser bitmap decoding. If the header is invalid or corrupted, it clearly reports that the file cannot be decoded.

Can I also convert the image while inspecting it?

Yes. Staged images remain ready for conversion into PNG, JPG, or WebP while displaying their inspection metadata.
